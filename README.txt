THÀNH NHÂN VUA - MACRO DESKTOP

Đây là ứng dụng macro mới, độc lập; không sửa trực tiếp file EXE cũ.
Chức năng: ghi thao tác chuột/bàn phím, phát lại đúng một lượt, dừng phát, lưu/mở macro JSON.
Không có Discord Token, đăng nhập Discord, gửi tin nhắn tự động hoặc vòng lặp vô hạn.

CÁCH TẠO EXE TRÊN WINDOWS 10/11:
1. Cài Python 3.11+ từ python.org và chọn Add Python to PATH.
2. Giải nén thư mục này.
3. Nhấp đúp install_and_build.bat.
4. EXE nằm trong dist\ThanhNhanVua.exe.

Lưu ý: Windows có thể hỏi quyền điều khiển chuột/bàn phím; chỉ dùng macro do bạn tự ghi và tin cậy.
